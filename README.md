# 수온 로그

스쿠버다이버가 입수 전에 다이빙 포인트의 수심별 수온을 확인하고 장비와 다이빙 계획을 준비하는 모바일 우선 웹앱의 초기 구조입니다.

## 실행

```bash
npm install
npm run dev
```

백엔드는 별도 터미널에서 실행합니다.

```bash
cp .env.example .env
npm run dev:server
```

기본 주소는 `http://127.0.0.1:8787`입니다.

### 백엔드 API

```text
GET /health
GET /api/sites?q=검색어
GET /api/sites/:siteId?date=YYYY-MM-DD
```

현재 `DATA_PROVIDER=mock`만 데이터를 반환합니다. `nifs` 또는 `copernicus`를 선택하면 실제 공급자 구현과 인증정보가 아직 없다는 `503` 응답을 반환합니다. 비밀값은 `.env`에만 저장하고 저장소에는 `.env.example`만 포함합니다.

## 테스트

```bash
npm test
```

개발 중 반복 실행은 `npm run test:watch`를 사용합니다. 수온 계산, 데이터 검증, API 오류·재시도·시간 초과, 로컬 저장 읽기·쓰기를 단위 테스트합니다.

## 구조

```text
src/
├── components/       재사용 UI
├── data/             개발용 포인트·수온 목업 데이터
├── domain/           포인트·수심별 수온 핵심 타입과 규칙
├── features/         기능 단위 화면과 로직
│   ├── dashboard/    선택한 포인트 수온 요약
│   ├── site-search/  다이빙 포인트 검색
│   └── saved-sites/  저장한 포인트
├── services/         외부 해양 관측 데이터 연결 인터페이스
└── styles/           전역 스타일과 디자인 토큰
server/
├── cache/            응답 메모리 캐시
├── config/           환경변수 검증
├── data/             서버용 포인트 목록
├── domain/           API 데이터와 오류 타입
├── providers/        목업·외부 데이터 공급자
├── routes/           상태·포인트 API
├── services/         검색·캐시·공급자 조합
└── index.ts          백엔드 시작점
```

## 현재 범위

- 홈, 포인트 검색, 저장한 포인트 화면의 이동 구조
- 다이빙 포인트와 수심별 수온 정보 타입
- 날짜와 예상 최대 수심에 따라 달라지는 수온 요약 및 수심 그래프
- 데이터 종류, 기준 위치와 거리, 갱신 시각 표시
- 과거에 사용한 장비를 확인하는 개인 기록 예시
- 다이빙 조건과 장비를 묶은 계획 저장
- 개인 장비 추가·삭제와 다이빙 후 실제 수온 기록
- 두 포인트 비교와 수온 변화가 큰 수심 구간 표시
- 선택 정보, 계획, 장비, 사후 기록의 브라우저 로컬 저장
- 오프라인 및 검색 결과 없음 상태 안내
- API 시간 초과·재시도·응답 형식 검사와 오래된 데이터 경고
- 입력값·로컬 저장값 검증 및 전체 화면 오류 복구 안내
- 외부 해양 관측 데이터 연동을 위한 경계
- 실제 기록과 분리된 화면 확인용 목업 데이터

수온 데이터 출처, 갱신 주기, 예보 여부, 섭씨·화씨 정책은 아직 확정하지 않았습니다.
